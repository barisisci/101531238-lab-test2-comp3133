# 101531238-lab-test2-comp3133

Angular app for COMP3133 lab test 2a. Pulls SpaceX launch data from `api.spacexdata.com` (v3). There’s a list with search + year filter, and a detail page per flight.

```bash
npm install
npm start
```

Build output ends up under `dist/101531238-lab-test2-comp3133/browser`. There’s a `vercel.json` if you deploy there.
